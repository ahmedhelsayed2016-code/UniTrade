### الملفات ودورها

| الملف | دوره في المشروع |
|---|---|
| `index.html` | فيه العنصر `root` وبيحمّل `src/main.jsx`. |
| `src/main.jsx` | نقطة بداية React. بيعرض `App` جوّه `root` وبيحمّل `index.css`. |
| `src/App.jsx` | المكوّن الرئيسي. الكود الحالي فيه عنوان `Get started` ومثال العدّاد. |
| `src/index.css` و`src/App.css` | تنسيق الواجهة. الأول بيتحمّل من `main.jsx` والتاني من `App.jsx`. |
| `src/pages/Register.jsx` و`src/pages/Login.jsx` | مكان صفحة إنشاء الحساب وصفحة تسجيل الدخول. |
| `src/pages/Home.jsx` و`src/pages/Profile.jsx` | مكان الصفحة الرئيسية وصفحة الملف الشخصي. |
| `src/components/Navbar.jsx` و`src/components/ProtectedRoute.jsx` | مكان شريط التنقّل ومكوّن التحقق من الدخول قبل عرض صفحة محمية. |
| `src/context/AuthContext.jsx` | مكان مشاركة حالة تسجيل الدخول بين مكوّنات الواجهة. |
| `src/services/api.js` | مكان تجهيز الاتصال بالـ backend لما توصل تفاصيل الـ API. |
| `package.json` و`package-lock.json` | الأول بيسجّل الحزم وأوامر المشروع. التاني بيسجّل الإصدارات اللي اختارها npm. |
| `vite.config.js` و`eslint.config.js` | إعدادات تشغيل وبناء الواجهة، وقواعد فحص الكود. |

### الحزم والقرارات

- حزم الواجهة المثبّتة وقت الفحص هي `react 19.3.1` و`react-dom 19.3.1` و`react-router-dom 7.18.6` و`axios 1.21.1`.
- من أدوات التطوير المثبّتة `vite 8.3.8` و`eslint 10.15.0`. باقي أدوات التطوير المباشرة المسجّلة في `package.json` موجودة كمان.
- هنكمل في المشروع الحالي عشان التقسيمة والحزم موجودين. Git متهيّأ محليًا، ومصطفى مأجّل GitHub لحد ما المشروع يخلص.

## تعلّم مصطفى

- **اتشرح** إزاي `index.html` بيحمّل `main.jsx`، وإزاي `main.jsx` بيعرض `App`. اتشرح كمان إن إنشاء ملف صفحة لوحده مش كفاية عشان تظهر.
- **مصطفى أكّد إنه فهم** لسه مفيش تأكيد مسجّل.
- **محتاجين نراجع سوا** مصطفى يتتبّع مسار عرض الصفحة بنفسه ويحدّد الملف اللي فيه العنوان الظاهر في مثال Vite.

## الـ Backend والـ APIs

- **العقود المستلمة** مفيش تفاصيل API اتسلّمت في الجلسة.
- **المطلوب من الفريق وقت الربط** الـ Base URL وتفاصيل endpoints التسجيل والدخول والملف الشخصي والخروج، وطريقة المصادقة. هنحتاج نعرف الـ methods والـ headers والحقول المطلوبة والاختيارية وشكل الردود والأخطاء والـ status codes وإعدادات CORS.
- **الربط والاختبار** مفيش API مربوط أو مختبَر في الواجهة الحالية.
- **الـ mock والتنفيذ المؤقت** مفيش mock مستخدم. مثال Vite لسه موجود في `App.jsx`.

## الاختبارات والمشاكل

- **نتيجة فحص الملفات** اتحدّد مسار عرض التطبيق، واتأكد وجود الحزم والملفات المذكورة فوق بالقراءة.
- **تشغيل التطبيق** مصطفى قال إن Vite اشتغل معاه قبل كده. تشغيل الواجهة في المتصفح ونتائج `build` و`lint` لسه ما اتراجعوش في الجلسة دي.
- **مشاكل اتصلحت** مفيش إصلاحات اتعملت في كود المشروع في الجلسة.
- **مشاكل مفتوحة** مفيش خطأ تشغيل محدّد اتبلّغ عنه.
